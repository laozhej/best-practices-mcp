# M2 — Public reads and host discovery

## Commitments

M2 registered `find_project`, `get_criteria` and `get_project_progress`, with bounded GET transport and the reference host's project-selection/read workflow. Public observations preserved identity, source/fetch metadata and supplied upstream values; they did not initialize or synchronize local drafts.

## Findings and fixes

A live read exposed the initial baseline's incorrect localized JSON routes. The implementation switched to the documented locale-independent `/projects.json` and `/projects/{id}.json` routes, retained redirect rejection and used canonical query encoding. Review distinguished collection-route failures from a missing project, made uncertain/exhausted pagination explicit, and removed upstream response bodies from diagnostics.

Inspector warned about Pydantic's legal but unrestricted `JsonValue` schema. Investigation reproduced the warning through ordinary SDK/Pydantic usage; it did not establish a specification violation or widespread failure in official servers. The adopted public `WithJsonSchema` annotation explicitly declares all JSON kinds while preserving runtime acceptance. Review and regression checks verified semantic equivalence. The [schema investigation](../mcp-schema-portability.md) records the rationale and SDK precedent.

## Outcome and limits

The public-read gate and reference-host slice passed independent review and deterministic/network tests. Read-only live probes confirmed selected API paths without proving the deployed revision. Document tools, persistent drafts and independent application-host acceptance remained later milestones. Inspector results supplemented, rather than replaced, protocol and model tests.
