# M0 — Planning and bootstrap review

## Commitments and decisions

The bootstrap review fixed a nine-tool scope around public BadgeApp reads, portable draft documents, optional project-keyed local storage, advisory validation and reviewable artifacts. Hosts retain reasoning, evidence selection, browser interaction and final saving. The originating Badge Buddy CLI provided development context rather than a parity requirement.

The plan specified exact tool inputs/results, errors, resource and network limits, source pins, transfer precedence and identity checks. A basic reference terminal host was required to demonstrate both caller-owned documents and optional persistence through the public MCP interface. Milestones paired technical gates with a small HTML report containing commitments, changes, open questions and reproducible commands.

## Findings and resolution

Independent reviews identified ambiguous transfer eligibility, incomplete validation semantics, missing URL/script result contracts, storage coordination promises broader than the intended scope, and insufficient host/package/platform acceptance criteria. The [review dispositions](../badgeapp-mcp-review-response.md), [concurrency decision](../badgeapp-mcp-concurrency-review.md) and [readiness checklist](../badgeapp-mcp-readiness.md) record the resolutions.

The settled storage design used one multi-level draft per registered project, process-local guards and atomic replacement. Cross-process coordination, revision tokens, automatic synchronization, blanket overrides and extra tool modes remained excluded. MCP 2026-07-28 obligations were assigned to the official SDK with actual wire-boundary checks.

## Outcome and limits

G0 was approved after the blocking design gaps were resolved. This approved a concrete implementation plan, not unbuilt behavior or publication. The existing scaffold checks established only startup/protocol/package foundations. Implementation and independent review continued at each milestone, with authenticated live QA and publication held as separate activities.
