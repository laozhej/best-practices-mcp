# M3 — Documents, validation and transfer artifacts

## Commitments

M3 added pure draft patching, optional mechanical validation, proposal URL construction, guarded form-fill scripts and the reference host's explicit-document workflow. Validation did not gate artifact generation. The server advertised seven tools; local draft persistence remained M4 work.

## Findings and fixes

Review found that permissive URL parsing could erase control characters from identity provenance. The comparison path now rejects those values before applying its conservative normalization. Script instructions were made explicit about replacing selected controls independently of URL overrides. Host imports now reject non-finite JSON and invalid Unicode before sending data to MCP, preserving the session and prior document after rejection.

Transfer decisions followed the documented status-first matrix: a divergent unforced status blocks its paired justification even when that justification is forced; an equal status does not. Inherited justification overrides survive pruning an unchanged forced status. URL artifacts preserve raw text while reports describe the agreed edit-form whitespace normalization; scripts preserve exact supplied text.

The conflicting upstream descriptions of `?` resets were recorded explicitly. The server makes no reset promise. Reports describe edit-form behavior against an observed public record, not Save/Submit acceptance or persisted values. Internal Ruby comparisons were development evidence; they later became optional diagnostics under the M5 testing-policy decision.

## Outcome and live verification

Independent scope and architecture review approved the implementation after corrections. Controlled DOM, wire, host and package checks passed. A subsequent authenticated Chrome session exercised eight transfer cases and baseline restoration, including a multi-criterion preview. Generated links clicked in the Codex UI worked, establishing a happy path beyond a host opening the browser directly.

The [live QA context](../../../live-qa/2026-11-09/README.md) records expectations, observations and screenshot status. The session did not save applications or establish equivalence with the previously reported Claude Code → TextEdit → browser copy-paste path. Persistence, platform qualification and independent application-host acceptance remained separate gates.
