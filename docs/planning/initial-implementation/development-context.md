# Initial development context

Portions of this MCP's code were extracted from the Badge Buddy plugin in `reponomics/plugins` after that plugin's CLI had been successfully exercised. That working CLI provided a starting point for the independent MCP implementation.

The extracted portions were adapted to this project's bounded tool surface and host/server responsibilities. The plugin was development context, not a requirement to reproduce its complete behavior or specification. Source provenance and licensing are documented separately.
